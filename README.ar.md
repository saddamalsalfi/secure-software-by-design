# هندسة البرمجيات الآمنة منذ التصميم

[English](README.md) · [ملف المهارة](skills/secure-software-by-design/SKILL.md) · [ترخيص MIT](LICENSE)

مهارة لوكلاء البرمجة تساعد في تصميم الضوابط الأمنية وتنفيذها ومراجعتها. تختار مسارًا يناسب حجم التغيير: إصلاح محدود، أو مراجعة تصميم شاملة، أو تطبيق تدريجي على مشروع قائم.

## التثبيت

انسخ **المجلد كاملًا** `skills/secure-software-by-design/` إلى أحد مسارات الاكتشاف في مشروعك، ولا تنسخ `SKILL.md` وحده؛ فهو يشير إلى المراجع والأدوات المرفقة.

| الوكيل | المسار في المشروع المستهدف |
|---|---|
| OpenAI Codex | `.agents/skills/` |
| Claude Code | `.claude/skills/` |
| GitHub Copilot | `.github/skills/` أو `.agents/skills/` في الواجهات المدعومة |
| Cursor | `.cursor/skills/` أو `.agents/skills/` |

تجد روابط التوثيق الرسمي ومثال التثبيت في [الدليل الإنجليزي](README.md#install). تثبيت المهارة مباشرةً لا يتطلب MCP أو Docker. أدوات التحقق المرفقة اختيارية وتتطلب Python 3.10 أو أحدث؛ وفاحص فروق التغييرات يتطلب Git.

## التشغيل عبر MCP وDocker

يتيح خادم MCP اختياري للقراءة فقط استعراض مراجع المهارة عبر `stdio` أو `Streamable HTTP`. يعرض `list_guidelines` الموضوعات ويقرأ `get_guidelines` مرجعًا محددًا. لا يصل الخادم إلى ملفات مشروعك ولا يشغّل سكربتات التحقق. راجع [دليل التشغيل والتوزيع](docs/distribution.md) لبناء صورة Docker وإعداد العميل.

## مثال استخدام

```text
استخدم مهارة secure-software-by-design لمراجعة ميزة تصدير السجلات.
حدّد قاعدة الوصول، وتحقّق من حالتي السماح والرفض باستخدام بيانات
اختبار اصطناعية، ثم اعرض الأدلة والفحوص غير المنفّذة والمخاطر المتبقية.
```

## الاختبار المحلي

```sh
python -B -m unittest discover -s tests -v
```

تفحص الاختبارات بنية الحزمة والروابط المحلية، وتختبر الأدوات بمستودعات Git مؤقتة وردود سجلات حزم محاكاة دون الاتصال بالخدمات الحية.
